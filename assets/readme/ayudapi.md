# AyudAPI — Plataforma de asistencia médica y métricas

Proyecto universitario en equipo: plataforma de asistencia médica con generación de QR de paciente único, web scraping para validar profesionales y métricas para obras sociales.

*University team project: medical assistance platform featuring unique patient QR generation, web scraping to validate professionals, and metrics for health insurance providers (obras sociales).*

## Funcionalidades principales

- **QR de paciente único:** identificación unívoca de cada paciente.
- **Validación de profesionales:** web scraping para verificar la matrícula / habilitación de profesionales médicos.
- **Métricas para obras sociales:** indicadores y reportes para la gestión.
